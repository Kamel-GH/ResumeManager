# v0.4 — Suivi de stabilisation

Branche de travail : `v0.4-stabilisation`

Objectif : stabiliser la branche `v0.4` sans changement fonctionnel visible, avant d'ajouter de nouvelles fonctionnalités lourdes.

## Règles de stabilisation

- Ne pas modifier le comportement utilisateur sans décision explicite.
- Préserver le modèle canonique `TemplateSchema -> RenderTree -> Renderer`.
- Ne pas mélanger refactor structurel et changement fonctionnel dans le même lot.
- Garder des commits courts, lisibles et réversibles.
- Valider localement après chaque lot avec `pnpm typecheck`, `pnpm test`, `pnpm build`.
